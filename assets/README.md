# Assets

The prototype currently draws placeholder pixel art directly with SDL3, so it does not need image files.

Add only original or properly licensed assets here. Suggested future folders:

- `sprites/` — player, NPC, and creature sprites
- `tilesets/` — route, town, and interior tiles
- `audio/` — music and sound effects

Keep sprite sheets in a consistent pixel-art style and document the source/license of any third-party asset.
