# Keyboard controls

Only these keyboard keys may be assigned to gameplay:

`W E T I A S D F G H J K Z X C V B M`

- `W A S D`: move up, left, down, right.
- Battle menu: `W` / `S` changes the selected row; `A` / `D` changes the column; `E` confirms the move.
- Party menu: `T` opens or closes the party; `W` / `S` selects a slot; `E` switches the active Pokémon.
- All future gameplay actions must use keys from the approved set above.
- Arrow keys, Enter, Space, Escape, and other keyboard keys are not gameplay controls.
- The operating-system window close button remains available.
